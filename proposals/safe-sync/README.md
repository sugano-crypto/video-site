# すがCon：安全な差分同期のレビュー候補

**本番適用前。既存の関数・Cronは変更していません。**

[調査結果・導入前条件・運用手順](docs/review-ja.md)を先に確認してください。

- 初期状態はdry-run。専用認証あり、自動削除なし。
- 3分間隔の差分同期＋03:00 JSTの全件再検証を提案。
- Webhook受信口、公開取り消しの自動非表示は未実装。特に後者は本番移行前の必須確認事項です。
- `sql/` はレビュー用。自動マイグレーションやデプロイ設定はありません。

テスト（Node.js 22以上、外部API/本番DBへは接続しません）：

```sh
npm ci
npm test
```

SQLはWASM版PostgreSQLのPGlite上で、検証用articlesスキーマを作って検証します。本番のスキーマ・RLS・トリガーとの互換性は別途確認が必要です。
